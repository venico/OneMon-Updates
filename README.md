# OneMon 下载与自动更新

OneMon 用于 Windows 11 和 Apple Silicon Mac 共用显示器：快捷键切换 DP / HDMI 输入，键鼠跟随，以及文本、文件和文件夹剪贴板共享。

本仓库仅发布安装包和更新说明，不存放私有源码、配对密钥或个人配置。

## 0.4.8

- 两端统一版本 0.4.8；配对码支持任意非空文字或数字，两端一致即可。
- Mac 新增全局切屏快捷键设置，支持 Command / Option 等组合。
- 更新后直接启动被替换应用内的运行时，保留启动日志。
- Mac 0.4.5 等旧版如更新后仍停留在旧版本，请退出旧版，从本页下载带版本号的 0.4.8 安装包，完整解压并覆盖后打开一次。之后两端都按统一版本更新。

## 下载

在 [最新版本](https://github.com/venico/OneMon-Updates/releases/latest) 选择：

- Windows：OneMon-Windows-v版本号-x64.zip
- M 系列 Mac：OneMon-macOS-v版本号-arm64.zip

更新前从托盘或菜单栏退出旧版，完整解压后替换应用，再打开。两端界面均显示版本号及对端版本；确认两端为同一新版。

## 0.4.7

- Windows 接收文件改存软件目录内的 Received 文件夹，修复资源管理器或微信粘贴时报“找不到项目”的问题；请将软件放到可写目录。
- Received 在自动更新时保留，不包含在源码或安装包中。
- DP 值和配对密钥旁使用清晰的圆形问号，点击显示对应说明。
- 安装包文件名带版本号。0.4.6 的无版本文件名附件仅用于兼容旧更新器；后续使用带版本号的文件。

## 0.4.5

- 优化鼠标移动不平滑：合并高频移动、减少 Mac 主线程积压，并连续记录光标位置。
- 修复 Mac 从 Finder 启动后，复制文件误报路径超出目录。
- 修复 Mac 更新后重新打开的流程：确认安装助手已启动，替换后通过系统打开新版，并等待原生客户端启动确认；失败回滚并保留日志。
- 32 项自动化测试、两端原生剪贴板测试及完整 Mac 应用替换重启测试通过；实际鼠标体感需实机验证。

如果当前仍是 0.4.3 或更早的 Mac 客户端，本次请退出旧程序后手动下载安装包替换一次，以升级旧更新器。后续使用新版自动更新。

## 0.4.2

- 界面显示本机和对端版本，文件共享状态单独显示。
- 文件接收完成后，确认成功写入系统剪贴板才提示可粘贴。
- 修复转发鼠标没有双击计数的问题，Mac 设置输入框双击全选。
- 自动检查本公开仓库的新版本，下载后校验 SHA-256、替换并重启；不需要登录或访问令牌。
- 自动更新保留现有配对和显示器配置，支持安装失败回滚及备份。

开启“自动更新”并保存后，启动约 15 秒和每 6 小时检查一次；也可点“检查并更新”。键鼠正在转发或文件正在传输时延后替换。安装目录需可写，Mac 源码运行方式需先改用打包的应用。

## 文件复制

两端开启共享剪贴板并连接。在资源管理器或 Finder 复制文件、文件夹或多个项目，等待“文件接收完成”，然后在目标文件夹粘贴。对端仍运行旧进程时会提示“未发送”，请先退出旧程序后重新打开新版。

文件扩展名不限，支持文件夹递归传输和完整性校验；最多一万个目录项。应用内位图、富文本、符号链接及云端未下载占位文件暂不支持。

Mac 客户端未签名、公证；首次使用需按系统提示允许打开，并授予辅助功能权限。
